### 🧠 Daily DSA: Move Zeroes to End

Given an integer array `nums`, move all `0`s to the end of it while maintaining the relative order of the non-zero elements.

**Constraint:** You must modify the array in-place without making a copy of the array.

**Example:**
`nums = [0, 1, 0, 3, 12]` ➔ Output: `[1, 3, 12, 0, 0]`

---

## Verified Solution (python)

```python
def move_zeroes(nums: list[int]) -> list[int]:
    # TODO: Place all non-zero elements at the front, then fill the rest with 0
    insert_pos = 0
    for x in nums:
        if x != 0:
            nums[insert_pos] = x
            insert_pos += 1
    for i in range(insert_pos, len(nums)):
        nums[i] = 0
    return nums
```
