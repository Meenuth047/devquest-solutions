### 🧠 Daily DSA: Finding the Unique Single Number

Given a non-empty array of integers `nums`, every element appears twice except for one.
Find and return that single one!

**Challenge:** Implement a solution with $O(N)$ linear runtime complexity and use only $O(1)$ extra space.

**Key Bitwise Insight:**
The XOR operator `^` has special properties:
- `x ^ x = 0` (any number XOR itself cancels out)
- `x ^ 0 = x` (any number XOR 0 is itself)
- XOR is associative and commutative!

---

## Verified Solution (python)

```python
def single_number(nums: list[int]) -> int:
    # TODO: Use XOR accumulator to cancel out duplicate pairs in O(1) space
    unique = 0
    for x in nums:
        unique ^= x
    return unique
```
