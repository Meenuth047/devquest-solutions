### 🧠 Daily DSA: Squares of a Sorted Array

Given an integer array `nums` sorted in non-decreasing order, return an array of the squares of each number, also sorted in non-decreasing order.

**Goal:** Achieve $O(N)$ runtime using two pointers from both ends.

**Example:**
`nums = [-4, -1, 0, 3, 10]` ➔ `[0, 1, 9, 16, 100]`

---

## Verified Solution (python)

```python
def sorted_squares(nums: list[int]) -> list[int]:
    # Two pointers comparing absolute values from left and right
    n = len(nums)
    res = [0] * n
    left, right = 0, n - 1
    idx = n - 1
    while left <= right:
        if abs(nums[left]) > abs(nums[right]):
            res[idx] = nums[left] ** 2
            left += 1
        else:
            res[idx] = nums[right] ** 2
            right -= 1
        idx -= 1
    return res
```
