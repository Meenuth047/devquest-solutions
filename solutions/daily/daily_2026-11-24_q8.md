### ⚡ Daily Drill: IPv4 Address Validator (Regex)

Write a regular expression pattern that strictly validates an IPv4 address string in dot-decimal notation: `X.X.X.X`.
Each octet `X` must be between `0` and `255`.

**Pattern format:** Match the entire string from `^` to `$`.

---

## Verified Solution (regex)

```regex
PATTERN = r"^((?:25[0-5]|2[0-4]\d|1\d\d|[1-9]?\d)\.){3}(?:25[0-5]|2[0-4]\d|1\d\d|[1-9]?\d)$"
```
