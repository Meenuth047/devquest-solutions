### 🐍 Python Mastery: Deep Flattening

Write a function `deep_flatten(nested) -> list` that takes an arbitrarily deeply nested structure of lists and tuples, and returns a flat 1D list containing all primitive leaf values.

Strings should be preserved as atomic items and not decomposed into characters!

**Example:** `[1, [2, 3], [4, [5, 6]]]` ➔ `[1, 2, 3, 4, 5, 6]`

---

## Verified Solution (python)

```python
def deep_flatten(nested) -> list:
    # Recursively unpack lists and tuples while preserving atomic values
    result = []
    for item in nested:
        if isinstance(item, (list, tuple)):
            result.extend(deep_flatten(item))
        else:
            result.append(item)
    return result
```
