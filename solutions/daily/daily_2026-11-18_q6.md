### 🐍 Python Mastery: Merge and Sum Dictionaries

Write a function `merge_and_sum_dicts(d1: dict[str, int], d2: dict[str, int]) -> dict[str, int]` that combines two dictionaries. If a key appears in both dictionaries, its value should be the sum of both values.

**Example:** `d1 = {'a': 10, 'b': 20}`, `d2 = {'b': 5, 'c': 30}` ➔ `{'a': 10, 'b': 25, 'c': 30}`

---

## Verified Solution (python)

```python
def merge_and_sum_dicts(d1: dict[str, int], d2: dict[str, int]) -> dict[str, int]:
    # Combine two dicts summing overlapping keys
    res = dict(d1)
    for k, v in d2.items():
        res[k] = res.get(k, 0) + v
    return res
```
