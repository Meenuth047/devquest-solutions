### 🐍 Python Mastery: Avoid Mutating While Iterating

In Python, removing elements from a list while iterating over it with a `for item in items:` loop skips adjacent elements due to index shifting!

**Task:** Write a function `remove_all_instances(items: list[int], val: int) -> list[int]` that returns a new list containing all elements from `items` except those equal to `val`.

---

## Verified Solution (python)

```python
def remove_all_instances(items: list[int], val: int) -> list[int]:
    # Safe idiom: construct filtered list rather than mutating during iteration
    return [x for x in items if x != val]
```
