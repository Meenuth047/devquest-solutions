### 🧠 Daily DSA: Merge Two Sorted Arrays

Given two sorted integer lists `nums1` and `nums2`, merge them into a single sorted list and return it.

**Goal:** $O(M + N)$ time complexity using two pointers.

**Example:**
`nums1 = [1, 3, 5]`, `nums2 = [2, 4, 6]` ➔ `[1, 2, 3, 4, 5, 6]`

---

## Verified Solution (python)

```python
def merge_sorted_arrays(nums1: list[int], nums2: list[int]) -> list[int]:
    # TODO: Merge two sorted lists in O(M + N) time
    i = 0
    j = 0
    result = []
    while i < len(nums1) and j < len(nums2):
        if nums1[i] <= nums2[j]:
            result.append(nums1[i])
            i += 1
        else:
            result.append(nums2[j])
            j += 1
    result.extend(nums1[i:])
    result.extend(nums2[j:])
    return result
```
