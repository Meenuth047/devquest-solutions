### 🧠 Daily DSA: Longest Common Prefix

Write a function to find the longest common prefix string amongst an array of strings `strs`.
If there is no common prefix, return an empty string `""`.

**Example 1:**
`strs = ["flower", "flow", "flight"]` ➔ `"fl"`

**Example 2:**
`strs = ["dog", "racecar", "car"]` ➔ `""`

---

## Verified Solution (python)

```python
def longest_common_prefix(strs: list[str]) -> str:
    # TODO: Compare characters across all words position by position
    if not strs:
        return ''
    prefix = strs[0]
    for s in strs[1:]:
        while not s.startswith(prefix):
            prefix = prefix[:-1]
            if not prefix:
                return ''
    return prefix
```
