### 🐍 Python Mastery: The Mutable Default Parameter Bug

In Python, default arguments are evaluated once at function definition time, NOT at each call.
When using mutable defaults like `registry: list = []`, modifications leak between calls!

**Task:** Fix `add_to_registry(entry: str, registry: list = None) -> list` so each call without `registry` uses a fresh list.

---

## Verified Solution (python)

```python
def add_to_registry(entry: str, registry: list = None) -> list:
    # Safe idiom: initialize fresh list if default None is passed
    if registry is None:
        registry = []
    registry.append(entry)
    return registry
```
