### 🧠 Daily DSA: Maximum Subarray

Given an integer array `nums`, find the subarray with the largest sum, and return its sum.

**Goal:** $O(N)$ linear time using **Kadane's Algorithm**.

**Example:**
`nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]` ➔ Maximum subarray `[4, -1, 2, 1]` has sum `6`.

---

## Verified Solution (python)

```python
def max_sub_array(nums: list[int]) -> int:
    # TODO: Kadane's algorithm: decide whether to extend previous subarray or start fresh
    max_sum = nums[0]
    current_sum = nums[0]
    for x in nums[1:]:
        current_sum = max(x, current_sum + x)
        max_sum = max(max_sum, current_sum)
    return max_sum
```
