### 🧠 Daily DSA: Find Pivot Index

Given an array of integers `nums`, calculate the pivot index of this array.
The pivot index is the index where the sum of all the numbers strictly to the left of the index is equal to the sum of all the numbers strictly to the index's right.

If no such index exists, return `-1`. If there are multiple pivot indexes, return the **left-most** pivot index.

**Example:** `nums = [1, 7, 3, 6, 5, 6]` ➔ `3` (Left sum: `1+7+3 = 11`, Right sum: `5+6 = 11`)

---

## Verified Solution (python)

```python
def pivot_index(nums: list[int]) -> int:
    # Track running left sum and compare with total - left_sum - x
    total = sum(nums)
    left_sum = 0
    for i, x in enumerate(nums):
        if left_sum == total - left_sum - x:
            return i
        left_sum += x
    return -1
```
