### 🐍 Python Mastery: Invert Dictionary

Write a function `invert_dict(d: dict) -> dict` that swaps keys and values in a dictionary where all values are unique and hashable.

**Example:** `{'a': 1, 'b': 2, 'c': 3}` ➔ `{1: 'a', 2: 'b', 3: 'c'}`

---

## Verified Solution (python)

```python
def invert_dict(d: dict) -> dict:
    # Swap keys and values using dictionary comprehension
    return {v: k for k, v in d.items()}
```
