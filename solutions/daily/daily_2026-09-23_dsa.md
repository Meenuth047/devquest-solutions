### 🧠 Daily DSA: Finding the Missing Number

Given an array `nums` containing `n` distinct numbers in the range `[0, n]`, return the only number in the range that is missing from the array.

**Goal:** $O(N)$ runtime with $O(1)$ extra space using Gauss's summation formula: $S = \frac{n(n+1)}{2}$.

**Example:**
`nums = [3, 0, 1]` ➔ Missing number is `2` (since range is [0, 3]).

---

## Verified Solution (python)

```python
def missing_number(nums: list[int]) -> int:
    # TODO: Calculate expected sum of 0..n and subtract actual sum
    n = len(nums)
    expected_sum = n * (n + 1) // 2
    return expected_sum - sum(nums)
```
