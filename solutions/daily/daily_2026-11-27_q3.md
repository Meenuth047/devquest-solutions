### 🧠 Daily DSA: Binary Search

Given a sorted array of distinct integers `nums` and a `target` integer, return the index of `target` if it exists in `nums`, or `-1` if it does not.

**Goal:** Must run in $O(\log N)$ runtime complexity.

**Example:**
`nums = [-1, 0, 3, 5, 9, 12]`, `target = 9` ➔ `4`

---

## Verified Solution (python)

```python
def binary_search(nums: list[int], target: int) -> int:
    # Divide and conquer with low and high pointers in O(log N)
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = (left + right) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
```
