### 🧠 Daily DSA: Bit Manipulation (Brian Kernighan)

Write a function `count_set_bits(n: int) -> int` that returns the number of set bits (`1`s) in the binary representation of a non-negative integer `n`.

**Key Insight:** `n & (n - 1)` always clears the least significant set bit in $O(1)$!

**Example:** `n = 7` (binary `111`) ➔ `3`

---

## Verified Solution (python)

```python
def count_set_bits(n: int) -> int:
    # Clear lowest set bit with n &= (n - 1) in each step
    count = 0
    while n > 0:
        n &= (n - 1)
        count += 1
    return count
```
