### 🐧 Daily Systems: Symbolic to Octal Permissions

In Unix systems, file permissions are represented as 9-character symbolic strings like `rwxr-xr--`.
Each 3-character triad represents User, Group, and Others where:
- `r` = 4 (Read), `w` = 2 (Write), `x` = 1 (Execute), `-` = 0 (No permission)

**Task:** Write a Python function `symbolic_to_octal(perm: str) -> str` that converts a 9-character permission string into its 3-digit octal string representation (e.g. `'rwxr-xr--'` ➔ `'754'`).

---

## Verified Solution (python)

```python
def symbolic_to_octal(perm: str) -> str:
    # Convert 9-char symbolic permission (e.g. 'rwxr-xr--') to octal ('754')
    weights = {'r': 4, 'w': 2, 'x': 1, '-': 0}
    res = []
    for i in (0, 3, 6):
        res.append(str(sum(weights.get(c, 0) for c in perm[i:i+3])))
    return ''.join(res)
```
