### 🧠 Daily DSA: Two-Pointer String Reversal

Write a function that reverses an array of characters `s` in-place.

**Constraint:** Do not allocate extra space for another array. You must do this by modifying the input array in-place with $O(1)$ extra memory.

**Example:**
`s = ["h","e","l","l","o"]` ➔ `["o","l","l","e","h"]`

---

## Verified Solution (python)

```python
def reverse_string(s: list[str]) -> list[str]:
    # TODO: Swap left and right pointers towards the center
    left = 0
    right = len(s) - 1
    while left < right:
        s[left], s[right] = s[right], s[left]
        left += 1
        right -= 1
    return s
```
