### 🔍 Daily SQL: Order Counts by Status

Table `orders` has columns `id` and `status`.
Write a query to select `status` and the count of orders for each status as `count`, ordered by `count DESC`, then `status ASC`.

---

## Verified Solution (sql)

```sql
-- Count orders per status:
SELECT status, COUNT(*) AS count
FROM orders
GROUP BY status
ORDER BY count DESC, status ASC;
```
