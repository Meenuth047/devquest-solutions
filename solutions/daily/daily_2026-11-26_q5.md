### 🐍 Python Mastery: Word Frequency Counter

Write a function `count_words(text: str) -> dict[str, int]` that splits a whitespace-delimited string and returns a dictionary of word frequencies.

If `text` is empty or only whitespace, return an empty dictionary `{}`.

**Example:** `text = 'apple banana apple orange banana apple'` ➔ `{'apple': 3, 'banana': 2, 'orange': 1}`

---

## Verified Solution (python)

```python
def count_words(text: str) -> dict[str, int]:
    # Count frequencies of whitespace-separated words
    counts = {}
    if not text.strip():
        return counts
    for word in text.strip().split():
        counts[word] = counts.get(word, 0) + 1
    return counts
```
