### 🧠 Daily DSA: Stock Profit Maximizer

You are given an array `prices` where `prices[i]` is the price of a given stock on day `i`.
You want to maximize your profit by choosing a single day to buy one stock and choosing a different day in the future to sell that stock.

Return the maximum profit you can achieve. If no profit is possible, return `0`.

**Example:**
`prices = [7, 1, 5, 3, 6, 4]` ➔ Buy on day 2 (price = 1) and sell on day 5 (price = 6), profit = `6 - 1 = 5`.

---

## Verified Solution (python)

```python
def max_profit(prices: list[int]) -> int:
    # TODO: Track minimum price seen so far and maximum profit in one pass
    if not prices:
        return 0
    min_price = prices[0]
    max_prof = 0
    for p in prices[1:]:
        if p < min_price:
            min_price = p
        else:
            max_prof = max(max_prof, p - min_price)
    return max_prof
```
