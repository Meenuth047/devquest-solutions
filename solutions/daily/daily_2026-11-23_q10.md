### ⚡ Daily Drill: Deduplicate Preserving Order

Write a Python function `unique_preserve_order(items: list) -> list` that takes a list and returns a new list with all duplicate values removed, preserving the order of their first appearance.

**Example:** `[1, 2, 2, 3, 4, 4, 1]` ➔ `[1, 2, 3, 4]`

---

## Verified Solution (python)

```python
def unique_preserve_order(items: list) -> list:
    # Deduplicate elements while preserving first appearance order
    seen = set()
    result = []
    for x in items:
        if x not in seen:
            seen.add(x)
            result.append(x)
    return result
```
