### ⚡ Daily Drill: High Stock Filter (SQL)

Table `products` has columns `id`, `name`, `price`, `quantity`.
Write a query to select `name` and `price` for products with `quantity > 50`, ordered by `price DESC`.

---

## Verified Solution (sql)

```sql
-- Filter products with quantity > 50 sorted by price DESC:
SELECT name, price
FROM products
WHERE quantity > 50
ORDER BY price DESC;
```
